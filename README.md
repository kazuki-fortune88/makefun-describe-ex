One word that sums up an ex: **knockoff**.

Why this word: a knockoff is a cheap imitation of the real thing — it looks
like a partner from a distance, but up close the stitching is wrong, the
logo is misspelled, and it falls apart after a month. It lands at a glance,
needs no caption, and anyone who has dated one recognises it instantly.
It is also the opposite of the obvious entries: not an insult like "toxic"
or "liar", but a verdict — my ex was never the genuine article.

## How to run

```sh
python3 main.py
```

This writes exactly one word, `knockoff` (8 characters), to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that variable
is not set. Nothing else is written.
